# Независимая проверка локального генеративного ядра NEUROGENESIS

## Итог

Подготовлен изолированный прототип настоящей авторегрессионной генерации через Transformers.js и ONNX. Основные файлы приложения и пользовательская память не менялись.

## Что проверено

- `node tests/local-llm.test.js` — 11/11 офлайн-тестов прошли на Node.js 22.16.0.
- `node --check` — синтаксис Worker, адаптера, тестов, fixture и локального сервера проверен.
- `dev/serve-local.mjs` — локальный HTTP-сервер поднят; тестовая HTML-страница вернула HTTP 200 и корректный `Content-Type`.
- Архив ZIP и patch созданы; patch проверен командой `git apply --check` и применением в пустом тестовом Git-репозитории.
- Контракт `NGLLMBridge` сверялся с действующим `llm-bridge.js` основного репозитория. При тестировании в реальном репозитории тестовый harness автоматически возьмёт настоящий файл вместо fixture.

Офлайн-тесты используют фиктивный runtime, Worker, Cache API и веса. Они подтверждают протокол обмена и обработку ошибок, но не качество генерации реальной Qwen3.

## Зафиксированные компоненты

- Модель: `onnx-community/Qwen3-0.6B-ONNX`.
- Проверенная ревизия Hugging Face: `a7b503b1c3f7e98e8f80b6d565f47807a5007d9c`.
- Runtime: `@huggingface/transformers@4.3.2`.
- Основной файл `onnx/model_q4f16.onnx`: около 570 MB; SHA-256 `9e33a5911974174761d0dfdcc0bec975d9c45af0eae5e9eb647b8ba9442a8f91`.
- CPU fallback `onnx/model_q4.onnx`: около 919 MB.

Источники фиксации версии: официальная страница коммита модели на Hugging Face и официальный релиз Transformers.js 4.3.2.

## Не проверено

- Реальная загрузка и запуск весов Qwen3.
- Фактическая генерация русских ответов.
- WebGPU и WASM fallback на Android.
- Скорость, пиковая RAM/VRAM, нагрев и устойчивость на целевом телефоне.
- Полный офлайн-перезапуск. Веса кэшируются отдельно, но runtime и WASM-зависимости загружаются с CDN; автономная работа пока не гарантируется.
- Контроль SHA-256 скачанных 570 MB. Сейчас кэш аудитится по размеру файлов, а не по вычисленному хэшу полного содержимого.

## Граница интеграции

Локальный адаптер изолирован. Он не подключён к основному чату, не выбирается автоматически и не меняет `memory.js`, `llm-bridge.js` или `index.html`. Для рабочего чата потребуется отдельное изменение `askWithLLM`: сейчас он проверяет `llmHttpAdapter`, поэтому одной регистрации нового провайдера недостаточно.

Никакие изменения не слиты в `main`. Для переноса доступны ZIP и Git patch.
