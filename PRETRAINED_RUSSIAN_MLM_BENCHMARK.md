# Предобученная русскоязычная MLM: эксперимент 0.1

## Задача

Проверить, улучшает ли готовая русскоязычная модель заполнения [MASK] восстановление скрытого слова относительно текущей небольшой word-level contextual-attention модели.

## Модель

Используется ai-forever/ruBert-base, зафиксированная на ревизии
05f37a2ca9e333fd18f30cd0c96c68d274793c69. Это модель Fill-Mask с BPE-токенизатором.
В эксперименте она применяется без дообучения на UD Russian-GSD: zero-shot baseline.

## Данные и изоляция

- Источник: UD Russian-GSD, commit 9acc9d677327043bd416fcc89e4b3407c620d885.
- 320 предложений train sample передаются внутренней модели.
- 100 предложений test sample используются только для оценки.
- Выборки дедуплицируются и проверяются на пересечение нормализованных предложений.
- Целевые позиции: NOUN, PROPN, VERB, AUX, ADJ, ADV, PRON и NUM.
- Для каждого целевого слова его поверхность заменяется на [MASK] до вызова ruBert; исходная пунктуация и пробелы сохраняются, когда word-offsets однозначно выравниваются с UD-токенами. Gold-форма используется только после инференса для подсчёта метрик.
- Внутренняя модель дополнительно делает собственное фиксированное разбиение train/validation/test из 320 train-предложений; фактическое число обучающих предложений записывается в отчёт.

## Сравнение

Сравниваются top-1 и recall@8:
1. по всем целям (слова, разбитые на несколько BPE-фрагментов, для одно-MASK ruBert считаются неуспехом);
2. на подмножестве слов, которые ruBert может представить одним самостоятельным токеном.

В отчёте отдельно указывается доля таких однотокенных целей. Результаты разбиваются по POS и по наличию целевого слова в словаре внутренней модели.

## Ограничения

Один [MASK] восстанавливает только один BPE-токен. Слова, разбитые токенизатором на несколько частей, не считаются корректно восстановленными. Это первый измерительный пилот, а не полная задача span-infilling и не обученная контекстная лемматизация. Модель не дообучается на UD в этом этапе.
