# NEUROGENESIS

**NEUROGENESIS** — экспериментальный прототип искусственного цифрового организма. Это новая чистая версия проекта, созданная без зависимости от прежнего HTML-файла.

## Что уже работает

- Интерактивная карта нейронов и синапсов с анимированными импульсами.
- Перемещение отдельных нейронов и панорамирование всего поля.
- Масштабирование колёсиком мыши, кнопками и жестом двумя пальцами (примерно от 16% до 550%).
- Полные подписи нейронов, выбор узла и инспектор параметров.
- Создание нейронов двойным нажатием, ручное соединение двух узлов и автоматический рост ветвей.
- Импульсная стимуляция и автономный демонстрационный режим.
- Локальное сохранение сети в браузере.

## Запуск

Откройте `index.html` в современном браузере. Для локального сервера из корня проекта:

```bash
python -m http.server 8080
```

Затем откройте `http://127.0.0.1:8080`.

На Android можно разместить репозиторий через GitHub Pages или запустить локальный сервер в Termux. Для сохранения данных разрешите браузеру хранить данные сайта.

## Структура

- `index.html` — интерфейс приложения.
- `styles.css` — оформление и адаптация под телефон.
- `app.js` — текущий браузерный runtime и визуальная симуляция.
- `engine/neuro_core.hpp`, `engine/neuro_core.cpp` — отдельное C++17-ядро: модель нейронов, синапсы, стимуляция и шаг симуляции.
- `engine/CMakeLists.txt` — сборка C++-ядра.

**Техническая оговорка:** браузерная версия 0.1 сейчас работает на JavaScript и не требует компилятора. C++-ядро добавлено как отдельный исходный модуль; оно пока не собрано в WebAssembly и не подключено к браузерному runtime. Это следующий этап, а не скрытая зависимость текущего прототипа.

## Принципы разработки

1. Сначала сохраняем работающий и проверяемый прототип.
2. Не добавляем тяжёлые зависимости без необходимости.
3. Любое усложнение модели сопровождаем наблюдаемым поведением и тестами.
4. Данные сети принадлежат пользователю и сохраняются локально в браузере.
