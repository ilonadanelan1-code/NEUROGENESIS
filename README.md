# NEUROGENESIS

**NEUROGENESIS 0.8** — экспериментальный браузерный прототип цифрового организма с визуальной нейронной сетью и локальной ассоциативной памятью.

## Что работает

- Интерактивная карта нейронов и синапсов, импульсы, выбор и инспектор нейронов.
- Перемещение узлов, панорамирование, масштабирование мышью и двумя пальцами.
- Создание нейронов, ручное соединение и демонстрационный режим активности.
- Автосохранение сети в браузере.
- Локальная память: до 500 записей, каждая — до 1200 символов.
- Разбиение введённого текста на фрагменты, выделение ключевых слов и поиск похожих сохранённых записей.
- Связь ключевых тем с отдельными энграммами в визуальной нейросети; повторное обучение усиливает память.
- Библиотека памяти: просмотр, поиск, редактирование, удаление и очистка.
- Экспорт и импорт резервной копии памяти в JSON.

## Важные ограничения

Это ещё не полноценный искусственный интеллект и не языковая модель. Поиск памяти пока основан на нормализации слов, простом стемминге и пересечении ключевых слов. Он может не распознать смысловой синоним или сложный контекст. Если надёжного совпадения нет, прототип должен сообщать об этом, а не выдумывать факт.

Память и история диалога хранятся в `localStorage` текущего браузера. Они не синхронизируются между устройствами и могут быть потеряны при очистке данных браузера. Для переноса или сохранения используй JSON-экспорт в панели памяти.

Визуальные нейроны, импульсы и энграммы — симуляция. Отдельное C++17-ядро в `engine/` пока не собрано в WebAssembly и не подключено к браузерному runtime. В текущем приложении также нет подключённой большой языковой модели и свободного рассуждения.

## Запуск

Открой опубликованную версию на GitHub Pages или запусти статический сервер из корня проекта:

```bash
python -m http.server 8080
```

Затем открой `http://127.0.0.1:8080`. Для сохранения данных браузер должен разрешать локальное хранилище сайта.

## Структура

- `index.html` — интерфейс приложения.
- `styles.css` — оформление и мобильная адаптация.
- `app.js` — визуальная симуляция, хранение сети и API энграмм.
- `memory.js` — локальная память, поиск, управление записями и резервные копии.
- `engine/neuro_core.hpp`, `engine/neuro_core.cpp` — отдельное C++17-ядро.
- `.github/workflows/pages.yml` — проверка JavaScript и публикация GitHub Pages.

## Принципы разработки

1. Сохраняем рабочую версию и проверяем изменения до публикации.
2. Не добавляем тяжёлые зависимости без необходимости.
3. Каждое усложнение должно давать наблюдаемое поведение и проверяемый результат.
4. Пользователь должен иметь возможность экспортировать и удалить свои локальные данные.
